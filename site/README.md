# 微信支付截图生成器（网站版）

微信 / 微信支付「**支付成功**」页截图生成器。单文件网页，零依赖，纯本地 Canvas 渲染，**无水印、无广告、不上传图片**。

## 直接打开

```
site/index.html      ← 双击即可，浏览器打开就能用
```

不需要安装、不需要联网（字体用系统字体）。手机上也能用，布局会自动变成上下两栏。

## 功能

| 字段 | 说明 |
|---|---|
| 用户头像 | 从相册/本机选图，自动裁圆；点右下角红色 × 或「清除」去掉 |
| 商品名称 | 显示在头像下方，支持 `**城`、`ki (***剑)` 这类打码写法，太长会自动缩字号 |
| 支付金额 | `128.00` 这种两位小数，失焦自动补全；「随机」一键换个金额 |
| 状态文字 | 默认「支付成功」，可改成「支付完成 / 已支付」等 |
| 状态颜色 | 微信绿 / 蓝 / 红 |
| 状态栏时间 | 左上角时间，如 `15:12` |
| 电池电量 | 状态栏电池里的数字，0~100 |
| 完成按钮 | 按钮文字，可改 |
| 开关 | 显示/隐藏手机状态栏；显示/隐藏底部「完成」按钮 |

导出：右上「保存 PNG」或面板「确定并保存」→ **750×1624 PNG（2 倍图）**；「复制图片」直接进剪贴板。

## 部署成真正的网站

整站就一个 `index.html`，丢哪都能跑：

**方式一：本地起服务（手机同 Wi-Fi 可访问）**
```bash
cd site
python -m http.server 8080
# 电脑：http://127.0.0.1:8080
# 手机：http://<电脑局域网IP>:8080
```

**方式二：GitHub Pages**
把 `site/` 里的 `index.html` 传到仓库根目录（或 `/docs`），Settings → Pages → 选分支目录，几十秒后拿到 `https://<用户名>.github.io/<仓库>/`。

**方式三：拖拽部署**
Netlify Drop / Vercel / Cloudflare Pages 都是把 `site/` 目录拖进去就上线，自带 HTTPS。

## 想加模板？

现在是「支付成功」单模板。同一套结构可以扩成：
- 转账成功 / 已收款 / 收款到账
- 红包领取页
- 账单列表 / 零钱明细

在 `render()` 里加分支，或在页面顶部加模板切换即可。

## 结构

```
site/

```
